# Optimat site

Soft-launch marketing + privacy pages for [Optimat](https://github.com/oscaraandersson/optimat-app) (Soft Glass).

## GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

Expected URLs:

- https://oscaraandersson.github.io/optimat-app/
- https://oscaraandersson.github.io/optimat-app/privacy.html

Static HTML only — no build step.
